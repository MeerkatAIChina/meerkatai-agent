# 用户文档

> Meerkat 桌面版使用说明（v0.1.1-alpha）。桌面版是把 qm 的完整能力（对话、模型路由、隐私锁、Skills、**沙箱执行**）封装成的单机应用——**不需要安装 Node、Docker，不需要懂命令行**，双击即用。

## 与网页版 qm 的差异

| | 网页版 qm | Meerkat 桌面版 |
|---|---|---|
| 形态 | 浏览器访问服务器 | 本地安装的桌面应用 |
| 部署 | 需要 Node/数据库/环境变量 | 一个安装包，双击安装 |
| 登录 | 账号登录 | 免登录（身份 = 本机） |
| 数据 | 服务器 Postgres | 本机 SQLite（`%APPDATA%\com.meerkat.desktop`） |
| 模型配置 | 管理员改配置文件 | 首次启动的图形设置页 |
| 启动 | 永久在线服务 | 清单式启动页，逐项点亮 |
| Skills | 管理员注册 | 启动时自动从仓库拉取 |
| 沙箱执行 | Docker 沙箱 | **内置 WSL2 沙箱**（v0.1.1 起，Windows） |

## 安装

运行 `Meerkat_0.1.1-alpha_x64-setup.exe`，按向导走完即可。覆盖安装不会丢任何数据（会话、令牌、配置都在用户目录，与安装目录分离）。

## 首次启动：设置页

第一次打开会进入设置页，配置项：

1. **服务令牌**（必填）：随交付包发给你的令牌字符串，粘贴后点"验证并保存"——系统会当场验证令牌有效性，通过才会保存
2. **本地模型服务地址 + 密钥**（选填）：如果你的组织部署了本地安全模型（处理涉敏内容用），填它的地址（如 `http://192.168.x.x:8000/v1`）。**不填的后果**：涉及隐私的内容将直接拒答（这是隐私设计，宁可拒答也不外发）
3. **网络代理**（选填）：如果你的网络访问 GitHub 不稳定（影响技能包拉取），填代理地址如 `http://127.0.0.1:7890`。保存后系统会自动重启核心服务生效
4. **沙箱**（v0.1.1 新增，选填）：见下节

保存成功后自动进入主界面。之后再打开应用会直接进入主界面，不再出现设置页。

## 沙箱（v0.1.1 新增）

沙箱是 AI 执行代码、读写文件时的隔离运行环境——模型生成的脚本在沙箱里跑，碰不到你的真实系统文件。

### 启用

- 设置页的「沙箱」区块显示当前状态。点「启用沙箱」会弹出一次 Windows 授权（UAC）请求，授权后按提示**重启电脑**即可
- 已启用过 WSL2 的机器：无需任何操作，首次启动时沙箱自动初始化（启动清单页沙箱行黄灯"初始化中"，秒级到 30 秒变绿灯）
- 不启用也能正常对话，只是代码执行/文件读写类工具不可用

### 出网限制（隐私设计）

沙箱内**不能自由访问互联网**，只放行白名单内的常用站点（pypi、npm 官方与镜像、GitHub、阿里云镜像）——模型现场装依赖、拉资料够用；访问白名单外站点会被拒绝。这是隐私承诺的一部分：沙箱里的代码不能随意外发数据。

### 沙箱里的文件

AI 在沙箱中创建的文件保存在沙箱自己的 workspace 里（`/home`），与你的 Windows 文件系统隔离。沙箱环境随应用升级更新时，系统会先自动备份你的 workspace 再更新，不会丢数据。

### 不支持的机器

以下情况沙箱不可用（对话、模型路由等其余功能完全正常）：

- Windows 10 版本低于 21H2（build 19044）
- BIOS 未开启虚拟化（VT-x）或无虚拟化的虚拟机
- 启用时拒绝了 Windows 授权请求

设置页沙箱区块会明确标注"此机器不支持沙箱"。

## 日常使用

### 对话与模型切换

界面与网页版一致：左侧栏 New chat / Projects / Chats / Files / Crons / Keychain / Apps / Memory / Skills。对话时可在顶部下拉切换模型——模型列表包含通用模型（gpt-5.4-nano、gemini-3.1-flash-lite）和本地模型 **Meerkat-TRIZ-v1**（v0.1.1 起可直接选择）。

**注意两个"切换不生效"的正常现象**（隐私路由设计，不是 bug）：

- 问 TRIZ 相关专业问题时，当前这一**轮**会自动走 TRIZ 模型回答，下一轮恢复正常
- 一旦对话中出现过身份证号、手机号等敏感内容，整个**会话**会被锁定到本地模型：之后所有轮都走本地模型，手动切换不生效，会话标题也可能不会自动生成。想用通用模型请另开新会话

### 🔒 锁标识（v0.1.1 新增）

会话被锁定后，底部的模型选择器会变成禁用态的 `🔒 Meerkat-TRIZ-v1` 按钮，一眼可见当前会话处于锁定状态。想解锁，点顶栏的锁管理入口进锁管理页操作。

### 隐私锁管理页

聊天页顶栏有 🔒 锁管理入口（v0.1.1 新增），点击进入 `/admin/locks` 管理页。能看到所有被锁定的会话，并支持两种管理操作：

- **重定向**：把锁改指到另一个可用模型（比如本地模型迁移了地址）
- **释放**：完全解除锁定（有警告确认；释放后历史敏感内容可能随后续请求发到云端，请确认你理解后果）

### Skills（技能包）

Skills 页展示已导入的技能（如 TRIZ 系列）。技能包在**每次启动时自动从仓库同步最新版**——无需任何操作。首次启动如果没拉到（网络问题），下次启动会自动重试；若你的网络需要代理，在设置页填上代理即可。

**如何触发技能**：

- **显式调用（最可靠）**：输入 `/技能名`（如 `/hello`、`/triz-verification`），agent 会立即读取并严格执行该技能
- **自然语言触发**：agent 会根据技能描述自行判断是否读取。对简单请求（如一句"你好"），模型可能直接作答而不读技能——这是模型的自主判断，不是故障。想要技能必答，就用 `/` 显式调用

### 启动页的状态灯

每次启动会显示组件清单：分类器 / 核心服务 / 知识包 / 沙箱 / 界面逐项点亮。

- **红灯（核心服务、界面）**：阻断启动，页面上显示原因，可点重试，或"复制诊断信息"发给支持人员
- **黄灯（知识包、分类器、沙箱等）**：不阻断，会放行进主界面，对应能力暂时退化

## 数据与隐私

- 所有数据在 `%APPDATA%\com.meerkat.desktop\`：会话数据库（meerkat.db）、令牌（加密存储）、配置（local-model.json / network.json）、沙箱虚拟磁盘（wsl/）、日志（logs/）
- 卸载应用**不会**删除这个目录；想彻底清空数据需手动删除该目录
- 重装/升级零迁移：直接覆盖安装即可

## 常见问题

**Q：涉敏问题被直接拒答了？**
本地模型没配置或服务不可达。这是隐私保护的正常行为。找管理员确认本地模型地址后在设置页配置（或请支持人员协助）。

**Q：沙箱里 pip/npm 装包装失败？**
先确认包源在白名单内（pypi、npm 官方/淘宝镜像、GitHub、阿里云镜像都在）。公司私有源暂不在白名单——联系管理员调整白名单配置。

**Q：启用沙箱时没弹授权窗/授权后还是"未启用"？**
启用 WSL2 需要重启电脑才生效。授权后重启系统，再打开应用即可。仍不行则在设置页"复制诊断信息"发给支持人员。

**Q：Skills 页一直是空的？**
技能包拉取需要访问 GitHub。如果你所在的网络直连 GitHub 不稳定，需要配置网络代理：删掉 `%APPDATA%\com.meerkat.desktop\` 下的数据后重走首启设置页填写，或让支持人员直接在该目录新建 `network.json`，内容为 `{"gitProxy":"http://127.0.0.1:7890"}`（地址换成你的代理），然后重启应用。

**Q：想换服务令牌？**
当前版本没有换令牌的 UI 入口（后续版本提供）。临时办法：删除数据目录后重走首启设置。

**Q：关窗后进程还在吗？**
不在。关闭窗口即回收全部子进程（含沙箱），无后台驻留。

# 需求描述

## 🌈 需求

### 需求一：桌面化的沙箱

#### 背景

QM 内置的 microVM 桌面不可用（microVM 的基础设施是云厂商托管服务）。桌面化需要有自己的内置沙箱，才能跑脚本、执行代码、操作文件等。

#### 具体需求

针对不同的系统，选择不同的沙箱，比如 win 使用原生 WSL2，macOS 使用   [Anthropic sandbox-runtime](https://github.com/anthropic-experimental/sandbox-runtime)，最后再用 [WASM runtime](https://github.com/bytecodealliance/wasmtime) 进行跨平台兜底。具体可以 review [QM沙箱现状调研](C:\Users\zhangYao\Desktop)。

## 🚀 优化

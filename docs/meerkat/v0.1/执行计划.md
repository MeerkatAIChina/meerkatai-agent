# Meerkat v0.1 桌面化交付物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Tauri v2 壳 + 随包 Node 运行时 + sidecar 三进程，把 meerkat 打包成交付客户的跨平台桌面应用，SQLite 全持久化。

**Architecture:** Rust 壳负责进程管理（动态端口分配 → spawn 三进程 → 健康轮询 → 崩溃恢复）、清单式启动页、首启引导和自动更新。core 侧新增 SQLite 双后端（DurableMap + SessionStore），web-ui 侧新增 `/setup` 设置页和桌面登录链路。会话与锁同生同死——都进同一个 SQLite 文件。

**Tech Stack:** TypeScript (core, Node ≥24.15), `node:sqlite` (Node 原生, DatabaseSync), Rust + Tauri v2 (壳), node:test + node:assert/strict (core 测试), tauri-plugin-updater (自动更新)

## Global Constraints

- 所有组织专属内容在 `deploy/layers/meerkat/desktop/` 下；core 的改动是 additive 的（新增 SQLite 后端、`/health` 端点、受控 skill 本地导入），不修改 v0.0 的语义路由、会话锁、Skills 核心逻辑
- **会话与锁必须同后端**：`SessionStore` 和 `sessionLockStore`（`artifactMap("session_locks")`）要么都内存、要么都 SQLite。桌面版 `SESSION_STORE=sqlite` 时两者必须都走同一个 SQLite 文件
- SQLite 用 Node 原生 `node:sqlite`（`DatabaseSync`，同步 API），不引入第三方 SQLite 驱动
- 代码零注释（AGENTS.md 规则）；计划示例代码中的中文注释仅供实施者理解，提交前须清除
- core 测试框架 `node:test` + `node:assert/strict`，运行命令 `node --experimental-test-module-mocks --test test/<file>.ts`
- 打包脚本在 `deploy/layers/meerkat/desktop/scripts/`，不进 `build.rs`（build.rs 只做 payload 目录存在性哑检查）
- 种子配置无秘密：真实 API key 永不进安装包、种子、随包文件

- [ ] **Step 1: 写 SQLite DurableMap 实现**

```typescript
// src/persistence/sqlite-map.ts
import { DatabaseSync } from "node:sqlite";
import type { DurableMap } from "./durable-map.ts";

function applyPatch<T>(value: T, patch: Partial<T>): T {
  const next = { ...value } as Record<string, unknown>;
  for (const [k, v] of Object.entries(patch)) {
    if (v === undefined) delete next[k];
    else next[k] = v;
  }
  return next as T;
}

export function createSqliteMap<T>(db: DatabaseSync, table: string): DurableMap<T> {
  if (!/^[a-z_][a-z0-9_]*$/i.test(table)) throw new Error(`invalid table name: ${table}`);
  db.exec(`CREATE TABLE IF NOT EXISTS ${table} (id TEXT PRIMARY KEY, json TEXT NOT NULL)`);
  const get = db.prepare(`SELECT json FROM ${table} WHERE id = ?`);
  const put = db.prepare(`INSERT INTO ${table} (id, json) VALUES (?, ?) ON CONFLICT (id) DO UPDATE SET json = excluded.json`);
  const insertAbsent = db.prepare(`INSERT OR IGNORE INTO ${table} (id, json) VALUES (?, ?)`);
  const del = db.prepare(`DELETE FROM ${table} WHERE id = ?`);
  const take = db.prepare(`DELETE FROM ${table} WHERE id = ? RETURNING json`);
  const all = db.prepare(`SELECT id, json FROM ${table} ORDER BY id`);

  const parse = (row: { json: string } | undefined): T | null =>
    row ? (JSON.parse(row.json) as T) : null;

  return {
    async all() {
      return (all.all() as Array<{ json: string }>).map((r) => JSON.parse(r.json) as T);
    },
    async entries() {
      return (all.all() as Array<{ id: string; json: string }>).map((r) => [r.id, JSON.parse(r.json) as T] as [string, T]);
    },
    async get(id) {
      return parse(get.get(id) as { json: string } | undefined);
    },
    async put(id, value) {
      put.run(id, JSON.stringify(value));
    },
    async putIfAbsent(id, value) {
      const existing = parse(get.get(id) as { json: string } | undefined);
      if (existing !== null) return existing;
      insertAbsent.run(id, JSON.stringify(value));
      return parse(get.get(id) as { json: string } | undefined) ?? value;
    },
    async insertIfAbsent(id, value) {
      const res = insertAbsent.run(id, JSON.stringify(value));
      return res.changes > 0;
    },
    async merge(id, patch) {
      const existing = parse(get.get(id) as { json: string } | undefined);
      if (existing === null) return null;
      const merged = applyPatch(existing, patch);
      put.run(id, JSON.stringify(merged));
      return merged;
    },
    async update(id, fn) {
      const existing = parse(get.get(id) as { json: string } | undefined);
      if (existing === null) return null;
      const next = fn(existing);
      put.run(id, JSON.stringify(next));
      return next;
    },
    async deleteIf(id, predicate) {
      const existing = parse(get.get(id) as { json: string } | undefined);
      if (existing === null || !predicate(existing)) return false;
      del.run(id);
      return true;
    },
    async delete(id) {
      del.run(id);
    },
    async take(id) {
      const row = take.get(id) as { json: string } | undefined;
      return parse(row);
    },
  };
}

export function createSqliteMapFactory(sqlitePath: string): {
  map<T>(table: string): DurableMap<T>;
  db: DatabaseSync;
} {
  const db = new DatabaseSync(sqlitePath);
  db.exec("PRAGMA journal_mode = WAL");
  return { map: <T>(table: string): DurableMap<T> => createSqliteMap<T>(db, table), db };
}
```

    assert.equal(u2[0]!.lastAt, mid.createdAt);
    assert.equal(u1[0]!.firstAt, early.createdAt);
    assert.equal(u1[0]!.lastAt, late.createdAt);

```typescript
// src/sessions/sqlite-session-store.ts
import { randomUUID } from "node:crypto";
import { DatabaseSync } from "node:sqlite";
import type { Session, SessionEntry, ScopeId } from "../types.ts";
import type {
  LeaseAttempt, NewEntry, NewTapeRecord, SessionStore, StoreOptions, TapeRecord,
} from "./session-store.ts";
import { isOverheardEntry, sessionOrigin } from "./session-store.ts";

const rowToSession = (r: Record<string, unknown>): Session => ({
  id: r.id as string,
  type: r.type as Session["type"],
  scopeId: r.scope_id as ScopeId,
  threadRef: r.thread_ref as string,
  ...(r.surface != null ? { surface: r.surface as string } : {}),
  createdAt: Number(r.created_at),
  ...(r.title != null ? { title: r.title as string } : {}),
  ...(r.channel_name != null ? { channelName: r.channel_name as string } : {}),
  ...(r.forked_from_session_id != null && r.fork_boundary_seq != null
    ? {
        forkedFrom: {
          sessionId: r.forked_from_session_id as string,
          ...(r.forked_from_title != null ? { title: r.forked_from_title as string } : {}),
        },
        forkBoundarySeq: Number(r.fork_boundary_seq),
      }
    : {}),
});

export function createSqliteSessionStore(sqlitePath: string, opts: StoreOptions = {}): SessionStore {
  const now = opts.now ?? (() => Date.now());
  const leaseTtlMs = opts.leaseTtlMs ?? 5 * 60_000;
  const db = new DatabaseSync(sqlitePath);
  db.exec("PRAGMA journal_mode = WAL");
  db.exec(`
    CREATE TABLE IF NOT EXISTS sessions ( ... );
    CREATE TABLE IF NOT EXISTS session_entries ( ... );
    CREATE TABLE IF NOT EXISTS participants ( ... );
    CREATE TABLE IF NOT EXISTS session_leases ( ... );
    CREATE TABLE IF NOT EXISTS session_tape ( ... );
    CREATE TABLE IF NOT EXISTS session_llm_requests ( ... );
  `);

  const stmt = {
    sessionByThread: db.prepare("SELECT * FROM sessions WHERE thread_ref = ?"),
    sessionById: db.prepare("SELECT * FROM sessions WHERE id = ?"),
    insertSession: db.prepare("INSERT INTO sessions (id, type, scope_id, thread_ref, created_at) VALUES (?, ?, ?, ?, ?)"),
    // ... 其余 statement 按需 prepare
  };

  return {
    // 35 个方法，逐个移植
    async getOrCreateByThread(threadRef, type, scopeId, channelName, surface) {
      const existing = stmt.sessionByThread.get(threadRef) as Record<string, unknown> | undefined;
      if (existing) {
        const s = rowToSession(existing);
        if (channelName && s.channelName !== channelName) { /* UPDATE */ }
        if (surface && !s.surface) { /* UPDATE */ }
        return s;
      }
      const session: Session = { id: randomUUID(), type, scopeId, threadRef, createdAt: now(), ...(channelName ? { channelName } : {}), ...(surface ? { surface } : {}) };
      stmt.insertSession.run(session.id, session.type, session.scopeId, session.threadRef, session.createdAt);
      return session;
    },
    async acquireLease(sessionId, holder): Promise<LeaseAttempt> {
      const row = stmt.leaseById.get(sessionId) as Record<string, unknown> | undefined;
      if (row && now() < Number(row.expires_at)) {
        return { lease: null, ...(row.holder ? { heldBy: row.holder } : {}), heldSince: Number(row.acquired_at ?? 0), heldUntil: Number(row.expires_at) };
      }
      const token = randomUUID();
      stmt.upsertLease.run(sessionId, token, now() + leaseTtlMs, holder ?? null, now());
      return { lease: { sessionId, token } };
    },
    async append(lease, entry: NewEntry): Promise<SessionEntry> {
      const row = stmt.leaseById.get(lease.sessionId) as Record<string, unknown> | undefined;
      if (!row || row.token !== lease.token) throw new Error("append without a valid session lease");
      stmt.extendLease.run(now() + leaseTtlMs, lease.sessionId);
      const maxRow = stmt.maxEntrySeq.get(lease.sessionId) as { n: number } | undefined;
      const seq = (maxRow?.n ?? -1) + 1;
      const full: SessionEntry = {
        sessionId: lease.sessionId, seq, parentSeq: seq === 0 ? null : seq - 1,
        type: entry.type, payload: entry.payload, scopeLabel: entry.scopeLabel as ScopeId, createdAt: now(),
      };
      stmt.insertEntry.run(lease.sessionId, seq, full.parentSeq, full.type, JSON.stringify(full.payload ?? null), full.scopeLabel, full.createdAt);
      return full;
    },
    // getEntries / appendTape / getTape / recordLlmRequest / addParticipant /
    // removeParticipant / listByParticipant / visibleEntries / listAll /
    // sessionsByThreadRefs / distinctScopes / scopeSessionSummaries /
    // lastUserMessages / scopeCronGroups / scopeSessionStats / attributedTurns /
    // listParticipants / participantsOf / deleteSession / updateTitle /
    // updateForkProvenance / releaseLease / forceReleaseLease / updateParticipantView /
    // getByThread / get / listLlmRequests / tapeCoverage
    // —— 全部对照 memory-session-store.ts 的同名方法，把 Map 读写替换成对应的
    //    SELECT/INSERT/UPDATE/DELETE，过滤逻辑（sessionOrigin/cronIdOf/isOverheardEntry）
    //    原样复用 JS 纯函数。
  };
}
```

**移植纪律**（其余方法不逐个贴代码，但必须遵守）：

1. 每个方法对照 `src/sessions/memory-session-store.ts` 同名方法逐行移植，Map 操作 → SQL 语句

- [ ] **Step 5: proc.rs —— 动态端口 + spawn**

```rust
// deploy/layers/meerkat/desktop/src-tauri/src/proc.rs
use std::net::TcpListener;
use std::process::{Child, Command};

fn free_port() -> u16 {
    let listener = TcpListener::bind("127.0.0.1:0").expect("no free port");
    listener.local_addr().expect("no addr").port()
}

pub struct Stack {
    pub classifier: Child,
    pub core: Child,
    pub web_ui: Child,
    pub classifier_port: u16,
    pub core_port: u16,
    pub web_ui_port: u16,
}

pub fn spawn_stack(node_path: &str, payload_dir: &str) -> Stack {
    let classifier_port = free_port();
    let core_port = free_port();
    let web_ui_port = free_port();

    let classifier = Command::new(node_path)
        .current_dir(format!("{}/classifier", payload_dir))
        .env("PORT", classifier_port.to_string())
        .env("ROUTES_PATH", format!("{}/config/seeds/routes.json", payload_dir))
        .spawn()
        .expect("spawn classifier");

    let core = Command::new(node_path)
        .current_dir(format!("{}/core", payload_dir))
        .env("PORT", core_port.to_string())
        .env("DATA_DIR", std::env::var("DATA_DIR").expect("DATA_DIR"))
        .env("SESSION_STORE", "sqlite")
        .env("CORE_SIGNING_SECRET", std::env::var("CORE_SIGNING_SECRET").expect("secret"))
        .spawn()
        .expect("spawn core");

    let web_ui = Command::new(node_path)
        .current_dir(format!("{}/web-ui", payload_dir))
        .env("PORT", web_ui_port.to_string())
        .env("CORE_API_URL", format!("http://127.0.0.1:{}", core_port))
        .env("CORE_ORG_ID", "meerkat")
        .spawn()
        .expect("spawn web-ui");

    Stack { classifier, core, web_ui, classifier_port, core_port, web_ui_port }
}
```

- [ ] **Step 2: 登录 token 注入 WebView**

按 Task 5 spike 结论二选一：

- **方案 A（header 注入成立）**：Tauri 用 `PORTAL_IDENTITY_SECRET` 签 `mintPortalIdentity({ p: "meerkat-desktop", exp: <long> })`，注入 WebView 初始请求的 `x-portal-identity` header；web-ui 验证通过后 `Set-Cookie` 续命
- **方案 B（header 注入不成立）**：token 经 query 传入 → 页面 JS 存储 → fetch 拦截器附加 `x-portal-identity`

Rust 侧签发逻辑（HMAC-SHA256，对齐 `portal-identity.ts`）：

```rust
use hmac::{Hmac, Mac};
use sha2::Sha256;
use base64::{engine::general_purpose::URL_SAFE_NO_PAD, Engine};

fn mint_portal_identity(claims: &str, secret: &[u8]) -> String {
    let payload = URL_SAFE_NO_PAD.encode(claims.as_bytes());
    let mut mac = Hmac::<Sha256>::new_from_slice(secret).expect("hmac");
    mac.update(payload.as_bytes());
    let digest = URL_SAFE_NO_PAD.encode(mac.finalize().into_bytes());
    format!("{}.{}", payload, digest)
}
```

**签名一致性约束**：TS 侧 `mintPortalIdentity`（`portal-identity.ts:14-17`）对 `JSON.stringify(claims)` 的 base64url 串做 HMAC。Rust 侧的 `claims` 参数必须与 TS 的 `JSON.stringify({ p, exp })` **逐字节一致**——key 顺序固定 `p`→`exp`、无空格、数字无科学计数法。建议不用通用序列化，直接用固定模板：

```rust
let claims = format!("{{\"p\":\"meerkat-desktop\",\"exp\":{}}}", expiry_ms);
```

一个字节不同（key 顺序、空格、数字格式）签名就永不匹配。

```yaml
# .github/workflows/desktop-release.yml
name: desktop-release
on:
  push:
    tags: ["desktop-v*"]
jobs:
  build:
    strategy:
      matrix:
        include:
          - os: windows-latest
            target: x86_64-pc-windows-msvc
          - os: macos-latest
            target: aarch64-apple-darwin
          - os: macos-13
            target: x86_64-apple-darwin
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - name: Stage payload
        run: bash deploy/layers/meerkat/desktop/scripts/stage-payload.sh
      - name: Build Tauri bundle
        run: |
          cd deploy/layers/meerkat/desktop/src-tauri
          cargo tauri build --bundles nsis,dmg
      - name: Upload installer
        uses: actions/upload-artifact@v4
        with:
          name: meerkat-${{ matrix.target }}
          path: deploy/layers/meerkat/desktop/src-tauri/target/release/bundle/
```

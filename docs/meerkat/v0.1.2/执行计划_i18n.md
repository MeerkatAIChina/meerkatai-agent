# i18n 中文化 执行计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 qm 全部用户可见界面（web-ui + admin + portal/auth）中文化，硬默认简体中文，无切换入口；同一遍完成品牌替换（QM→MeerkatAI、Meerkat→MAPID）。

**Architecture:** mini-lit 同源 i18n 机制：英文原文即 key，zh 字典集中单文件（`plugins/web-ui/src/locale/zh-cn.ts`），boot 时注入。未翻译串自动回退英文。admin 为无构建静态单文件，自起同约定的 `t()` 字典；portal/auth 服务端渲染页直接替换中文。

**Tech Stack:** Lit 3 + `@mariozechner/mini-lit`（已有依赖，导出 `i18n/setTranslations/getTranslations`）、Vite 7、node:test + jsdom。

**Spec:** `docs/meerkat/v0.1.2/设计文档.md`「UI 界面 i18n 中文化」章节——计划从设计文档出发论证，执行时两份一起读。

## Global Constraints

- **零注释规则**（AGENTS.md）：任何提交代码不得含注释；设计文档/本计划中的示例注释仅用于说明，提交前必须清除。
- 硬默认中文：boot **无条件** `localStorage.setItem("language", "zh")`；不做切换入口；不调 `setLanguage()`（它会 reload 页面）。
- `setTranslations` 是**整体替换**：必须 `{ ...getTranslations(), zh: ZH_CN }` 展开合并，禁止裸替（会清掉 en/de 导致 en 回退窗口 TypeError，jsdom 必踩）。
- 动态串一律走 `tr()` 防崩 helper，禁止裸写 `i18n(key)(args)`（key 未命中时 i18n 返回字符串，再调用即 TypeError）。
- **组件一律从 `locale/index.ts` import `i18n`（安全包装版），禁止直接从 `@mariozechner/mini-lit` import**——裸 Node/无 storage 环境（jsdom 测试、隐私模式、sandboxed iframe）下 mini-lit 的 `getCurrentLanguage()` 每次调用都读全局 `localStorage`，会抛 ReferenceError/SecurityError；安全包装统一回退英文 key（实测：Node v24.15.0 裸环境 `typeof localStorage === "undefined"`）。
- 品牌替换口径：QM→MeerkatAI、Meerkat→MAPID，仅用户可见串；代码标识符/包名/路径/注释不动。
- 术语表以设计文档第五节为准（Skill→技能、Session→会话、Cron→定时任务、Provider→供应商、Memory→记忆、Webhook/Harness/API/token 保留原文等）。
- 提交信息格式：type(scope) 英文 imperative，如 `feat(web-ui): localize chat surface to zh-CN`；每个 Task 结束提交一次。
- 测试命令在 Windows 上必须经 **Bash 工具**运行（npm scripts 含 POSIX 环境变量前缀，PowerShell 跑不了）。
- 工作分支：`feature/meerkat`，禁止动 `main`。

- [ ] **Step 4：实现 `locale/index.ts`**（i18n 为安全包装版——裸 Node/无 storage 环境下回退英文 key 而不是抛错）

```ts
import { getTranslations, i18n as miniLitI18n, setTranslations } from "@mariozechner/mini-lit";
import { ZH_CN } from "./zh-cn.ts";

export function i18n(key: string): unknown {
  try {
    return miniLitI18n(key);
  } catch {
    return key;
  }
}

export function tr(key: string): (...args: unknown[]) => string {
  const v = i18n(key);
  return typeof v === "function" ? (v as (...args: unknown[]) => string) : () => String(v);
}

export function setupLocale(): void {
  try {
    localStorage.setItem("language", "zh");
  } catch (e) {
    console.debug("locale: language preference not persisted", e);
  }
  setTranslations({ ...getTranslations(), zh: ZH_CN });
}
```

- 命中模式（启发式，允许误报、不允许漏报大类）：
  1. html 模板内的英文文本节点：`>` 与 `<` 之间含 ≥2 个连续英文单词
  2. `title="..."`、`placeholder="..."`、`aria-label="..."`、`label="..."` 属性值为英文
  3. `confirm("...")` / `alert("...")` / `throw new Error("...")` 中的英文
- 豁免：已包 `i18n(`/`tr(` 的同一行；纯插值 `${...}`；术语表保留原文词（MeerkatAI、MAPID、API、Webhook 等，脚本内 allowlist）

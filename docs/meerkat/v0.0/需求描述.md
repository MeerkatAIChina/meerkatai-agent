# 需求描述

## 背景

当前这个项目是从 `https://github.com/yc-software/qm` fork 而来，我需要在这个项目上进行二次开发，交付给客户使用。

### 产品定位

企业级的 Agent 平台

### 客户定位

客户都是**消费品行业**的公司，比如照明行业的雷士照明、化妆瓶行业的人花西子、人体工学椅的黑白调、纺织行业的罗莱，等等。

### 功能定位

1. TRIZ 创新领域的验证。
2. 产品概念设计。
3. 市场机会商业价值预估。
4. 产品卖点分析和包装。
5. 产品机会挖掘等咨询
6. 电商文案。
7. 等其他消费品行业的功能······

## 需求

### 模型切换与数据安全分级路由矩阵

前提：我们有自己训练的模型 [Meerkat-TRIZ-v1](https://huggingface.co/Meerkat-AI/Meerkat-TRIZ-v1)，该模型目前主要训练了 TRIZ 领域。

预期：所以我们需要在这个 Agent 中运行两套模型，一个是通用大模型，一个是安装在本地的自训练模型。

安全与隐私：模型切换需要考虑到**隐私数据脱敏**的问题。我有一个想法，就是采用 `数据分级 x 路由策略矩阵` 的方案。具体来说就是先对数据进行敏感度的 level 标记。比如：不敏感的 Level 3，中等敏感的 Level 2，高度敏感的 Level 1，高敏感的禁止接入通用模型，中等敏感的需提醒用户确认，不敏感的可以直接接入无需提醒确认。

综上所述，当 Agent 处理用户有关 TRIZ 领域的问题或 Agent 遇到企业隐私安全的相关问题时，就会切换到 TRIZ 模型。

### 业务层面的领域包

在`功能定位`章节，我已经提到了一些业务层面的能力，这些能力往往需要依赖于具体的 Skills。Skills 包含了这些业务层面的处理方法大纲，Agent 在遇到用户问题时，必须能够准确命中这些 Skills，避免产生幻觉。

### 技术层明的要求

二开必须保证项目版本的连贯性，能不改内核的尽量不要修改内核，且版本能够随主仓升级。所以，我希望二次开发的这些功能，能够以模块插拔的形式安装到 qm 上。

# 执行计划

## 任务拆分

### 任务 1：新增 `src/files/sqlite-file-artifact-store.ts`

**目标**：实现基于 SQLite 的 `FileArtifactStore`。

**步骤**：

1. 新建 `src/files/sqlite-file-artifact-store.ts`。
2. 导入 `openSqliteDatabase` 和 `DurableByteStore`。
3. 定义 `SCHEMA` 数组（`CREATE TABLE IF NOT EXISTS file_artifacts` + 三个 index）。
4. 实现 `rowToArtifact`：将 SQLite 行（含 INTEGER 0/1）转换为 `FileArtifact`（含 boolean）。
5. 实现 `createSqliteFileArtifactStore(sqlitePath, byteStore)`，返回 `FileArtifactStore & { close(): void }`。
6. 构造时打开 db、启用 WAL、执行 schema。
7. 预编译所有 SQL 语句并复用。
8. 实现接口方法：`put`（使用 `INSERT ... ON CONFLICT (id) DO NOTHING` 保证并发幂等，显式写入 `source = 'live'`）、`get`、`open`、`listOwnedByScopes`（`owner_scope_id IN (?, ?, ...)` 占位符）、`resolveByOwnerPaths`（`(owner_scope_id = ? AND path = ?) OR ...` 条件拼接）、`setEnabled`、`delete`。

**验收标准**：

- 新增文件通过 TypeScript 类型检查。
- `put` 对同一 id 幂等，不重复写入 byte store。
- `listOwnedByScopes` 排序/分页/过滤行为与 Postgres 版一致。

---

### 任务 2：修改 `src/config.ts`

**目标**：让配置系统识别 `ARTIFACT_STORE=sqlite` 并正确解析 `sqlitePath`。

**步骤**：

1. 在 `Config` 接口新增 `artifactStore: "memory" | "postgres" | "sqlite"`。
2. 解析 `env.ARTIFACT_STORE`，只允许 `memory`/`postgres`/`sqlite`，默认 `memory`；非法值显式抛错。
3. 放宽 `sqlitePath` 解析条件：`needsSqlite = SESSION_STORE === "sqlite" || ARTIFACT_STORE === "sqlite"`。
4. 更新 `DATABASE_URL` 互斥检查：覆盖 `ARTIFACT_STORE=sqlite`。
5. 移除 `src/config.ts:665-670` 对 `ARTIFACT_STORE=sqlite` 的禁止抛错。
6. 在返回的 config 对象中加入 `artifactStore` 和 `sqlitePath`。

**验收标准**：

- `ARTIFACT_STORE=sqlite` 且 `DATA_DIR=/tmp/x` 时，`config.sqlitePath === "/tmp/x/meerkat.db"`。
- `ARTIFACT_STORE=sqlite` 且 `DATABASE_URL=...` 时，启动抛错。
- 不设置 `ARTIFACT_STORE` 时，`config.artifactStore === "memory"`。

---

### 任务 3：修改 `src/wiring.ts`

**目标**：让 `fileArtifactStore` 按配置路由到 SQLite。

**步骤**：

1. 导入 `createSqliteFileArtifactStore`。
2. 修改 `files` 变量赋值：
   - `databaseUrl` 存在 → Postgres。
   - `artifactStore === "sqlite" && sqlitePath` → SQLite。
   - 否则 → memory。

**验收标准**：

- 无 `DATABASE_URL` 且 `ARTIFACT_STORE=sqlite` 时，调用 `createSqliteFileArtifactStore`。
- `DATABASE_URL` 存在时，仍调用 `createPostgresFileArtifactStore`。
- 两者都不满足时，仍调用 `createMemoryFileArtifactStore`。

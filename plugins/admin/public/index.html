自治

代理在无人监督时如何推理、行动和回应。

安全姿态

决定此范围内 Harness 获得的自治程度。组织级设置是下限；更小的范围可以收紧但不能放宽。身份、租户隔离、凭据范围、撤销和审计始终强制执行。

审批授权选项

审批卡片除了「允许一次」之外还提供哪些长期选项。与组织值按「只收紧」组合；禁用某模式也会同时暂停该模式的现有授权，直到重新启用。预声明命令审批和严格姿态的工具审批都遵循此设置。

外部 Slack 参与者

组织级，默认关闭。开启后，内部成员可以在受众包含外部用户（Connect 成员或访客）的 Slack 频道中与代理对话 — 代理的回复以及它在那里读到的任何内容都对那些外部人员可见。外部人员自己仍无法与代理互动。

环境感知行为

组织级，默认开启。关闭后，无论各频道如何设置，代理在任何频道都不会对听到的消息采取行动 — 只响应直接 @提及。

频道置顶横幅

组织级，默认关闭。开启后，代理会在它所在的每个 Slack 频道发布并置顶一条短横幅（注明当前使用的模型）。各频道仍可在自己的项目页面上覆盖此设置。

模型与浏览

未来轮次可用的模型、浏览器运行时和组织上下文。

交互轮次的 Fast 模式

组织级，默认关闭。开启后，人工轮次在支持 Fast 模式的模型上默认以 Fast 模式运行，除非该轮另有指定。需要供应商提供 Fast 模式额度。

Individual authorization for AI usage

Org-wide, default off. When on, each user must connect their own Claude or Codex account (API key or subscription login) before using the assistant. The org's shared model credentials are not used for their turns.

默认 Harness 和模型

没有覆盖设置的范围所继承的运行时。从下一轮开始生效。

批准的 Harness

用户可以在网页 UI 中选择或要求代理使用的 Harness。

允许的模型

组织级限制网页 UI 提供和接受哪些模型。添加要允许的模型并选择默认预选项。移除全部标签则允许部署的完整模型集。

品牌

决定此组织各界面的外观。Accent 是网页 UI、管理后台和门户中的强调色；mark 是网页 UI 中 1–2 个字符的徽标；label 是助手自我介绍时使用的名字；organization name 是助手称呼此组织的方式。字段留空则使用部署默认值。

人员名录

代理可以查询某人当前职务或头衔的公开页面或 URL（例如 https://www.example.com/people）。用于了解一个人。留空则禁用。

Slack ack emoji

The emoji the bot may react with to acknowledge a Slack message, org-wide. Add names from the workspace's emoji (custom and standard). Remove every chip to restore the built-in rotation.

浏览模型

组织级驱动 browse 技能中浏览器代理的模型。保持默认则跟随部署的基础模型。Fast 模式仅在 Opus 模型上可用；其他模型以标准速度运行。

浏览步数上限

组织级单个浏览任务允许的最大浏览器步数。每一步是浏览器代理的一个动作（点击、输入、导航）。留空使用默认值 50。

轮次时间上限

组织级单轮的最大墙钟时间。可填 60–86400 秒，0 表示不限制，留空使用部署默认值。
